# E-Learning Platform Redesign (E-Lae Ltd)

A modern, high-converting E-Learning platform landing page for E-Lae Ltd, featuring an interactive district campus locator, live career track funnel, dynamic syllabus detail drawers, and optimized course offerings.

## Key Features

- **Mega Navigation Menu:** Category-driven browsing with hover bridges and direct curriculum pathways.
- **Featured Course Tracks:** Modern card layouts with transparent pricing, EMI options, and real-world project counts.
- **Dynamic Syllabus Modal:** In-depth module breakdowns, industry tool badges, and instructor profiles aligned with official NSDA standards.
- **Interactive 64-District Campus Locator:** Real-time campus filtering across all divisions with authentic district map thumbnails and direct Google Maps navigation.
- **Career Funnel (ROI Alternative):** 3-step interactive assessment guiding students directly into tailored career programs.
- **Fully Responsive:** Optimized with Tailwind CSS, custom animations, and mobile drawer navigation.

## Tech Stack

- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (CDN)**
- **Lucide Icons**
- **Google Fonts (Hind Siliguri & Inter)**
